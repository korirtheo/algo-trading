# Deployment 2026-07-16: Crash Recovery & Bug Fixes

## Summary

Deploy critical fixes to resolve position monitoring failures and implement persistent state tracking to survive crashes/restarts.

## Root Cause Analysis

**TGHL Incident (2026-07-16):**
- Third position entered at 09:41 @ $1.56 (4403 shares)
- Dashboard crashed immediately after with `AttributeError: 'CombinedEngine' object has no attribute 'active_position'`
- Position NOT monitored for trail/stop despite current price $1.28 being -17.9% (should have hit -25% stop)
- First two positions exited via trail but logged 4-5 duplicate EXIT records each

**System Gaps:**
1. No persistent position state — all metadata (entry, peak, strategy, stop/target) lost on crash
2. Orphaned positions after restart — Alpaca has positions, system doesn't know what to do
3. `active_position` bug still deployed (fixed locally but not on AWS)
4. Duplicate trade logging from cumulative filled_qty bug

## Changes

### 1. Persistent Position State Manager
**New file:** `live/position_state.py`
- Saves position metadata to `logs/position_state.json` on every entry/peak update
- Tracks: order_id, strategy, entry_price, shares, peak_price, stop_price, target_price, trail_pct, time_limit
- Survives crashes, restarts, Docker container recreation
- Reconciles with Alpaca on startup to recover orphaned positions

### 2. Engine Integration
**File:** `live/engine_combined.py`
- Import PositionStateManager
- Save position state on BUY fill (after ENTRY log)
- Update peak price on every bar for active positions
- Remove position state on SELL complete exit
- Re-entry price floor filter: only allow re-entry if price > last_exit * 1.01

### 3. Crash Recovery Enhancement
**File:** `live/main.py` `recover_open_positions()`
- Use `engine.position_state.reconcile_with_alpaca()` to match Alpaca positions with saved state
- **Positions with full metadata:** Resume normal monitoring with original strategy/stop/target/trail/peak
- **Orphaned positions (no state):** Apply defensive rules (5% stop, 10% target, 1% trail)
- **Breached positions:** Immediately sell if stop/target already hit during downtime
- FIX: Use `engine.active_positions.add(ticker)` instead of singular `active_position = ticker`

### 4. Bug Fixes
**File:** `live/engine_combined.py` (lines 1091-1145)
- **Duplicate trade records:** Track `last_recorded_qty` in pending_orders, only process delta fills
- Applied to both BUY and SELL fill handlers

**File:** `dashboard/backend/services/engine_bridge.py` (line 561)
- Dashboard crash: `self.engine.active_position` → `list(self.engine.active_positions)[0] if self.engine.active_positions else None`

**File:** `live/streamer.py` (line 149)
- Raw bar logging path: Use `/app/logs` directly instead of calculating via `__file__`

**File:** `live/main.py` (line 137)
- Recovery bug: `engine.active_position = ticker` → `engine.active_positions.add(ticker)`

### 5. Re-Entry Price Floor Filter
**File:** `test_green_candle_combined.py` (lines 1077, 1608, 2915-2917)
- Track exit prices per (ticker, strategy)
- Only allow re-entry if current price > last_exit * 1.01 (1% buffer)
- Ensures momentum continuation vs catching falling knife
- Backtest validation: Blocks 11 re-entries (41 → 30), keeps 24 winners ($90K), 6 losers (-$5K)

**File:** `live/engine_combined.py` (lines 188, 412, 1246)
- Implement in live engine with `self.exit_prices` dict
- Check on entry: skip if `entry_price <= last_exit * 1.01`
- Record on exit: `self.exit_prices[(ticker, strategy)] = actual_avg`
